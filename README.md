# 笔记问答机器人（Agent 版）

用自己的 **28 篇 Python 学习笔记**当语料，外加一本 **SQLite 账本**，做成一个
**会自己决定「查不查、查几次、要不要记账」**的助手。

- **在线体验**：<https://www.modelscope.cn/studios/budon777/notes-qa-bot>（国内直连，不用梯子）
- **命令行**：`python 主程序.py "闭包是什么"`
- **浏览器**：`web\` 那层 FastAPI 服务，一个输入框点「问」

**一句话原理：模型没有手。** 它只能写一张「申请单」（说"我要查闭包"），
真正去翻笔记、查账、写字的是我的代码。这张单子写完，我把结果塞回去，它再接着说。

## 它现在长什么样

```
你问一句
   │
   ▼
主程序.py ──► 寄出：规矩 + 你这句 + 三只工具的菜单
   │
   ▼
模型回话（二选一）
   ├── 直接说话 ──────────────────────────► 打印到屏幕，结束
   │
   └── 递申请单（可能一张，可能两张一起）
         │
         ▼  我按 function.name 查表执行
         ├─ search_notes(查询词) ──► 检索.py 挑 3 块 ──► 笔记原文
         ├─ read_ledger(月份,分类) ─► SQLite 查账      ──► 几行数字
         └─ add_expense(金额,分类,日期,备注)
                     │
                     └─► 先问人 y/n（终端里）── n 就一笔不动
         │
         ▼  结果作为 role="tool" 的一条消息塞回本子
   带着结果再寄一次（最多 5 轮）
```

三件最容易搞混的事：

1. **模型不执行函数。** 它只是返回一个结构化的「调用请求」，带名字和参数。
2. **工具函数的返回值就是它的全部视野。** 我塞几行它就看见几行，所以工具里要压成几行字。
3. **失败也要占一条 `tool` 消息。** 少一条，下一次请求直接 400。

## 怎么跑

```powershell
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

两个 Key，都从环境变量读，代码里一个字都没有：

```powershell
setx DEEPSEEK_API_KEY  "你的 DeepSeek Key"        # 说话、写申请单
setx SILICONFLOW_API_KEY "你的硅基流动 Key"        # 把文字变成向量，检索用
```

> `setx` 只对**之后新开的**终端生效 —— 它改的是注册表，不是当前这个窗口。

在 `问答机器人\` 目录下：

```powershell
python 主程序.py "闭包是什么"     # 问完这一个就退出，答案边到边打出来
python 主程序.py                  # 交互模式：一直问，空回车退出（跨问题记得上文）
```

问句里有空格**要加引号**，否则会被拆成几个词再拼回去，空格被抹平。

第一次跑会做一件事：把 `记账演示.db`（21 笔母本，只读）复制成 `我的账本.db`。
之后记账写的是后者；想回到 21 笔，删掉 `我的账本.db` 再跑一次。

## 怎么验收 —— 这个项目最像工程的部分

不看"感觉好像对"，看四个能数的东西：

```powershell
python 测试_检索.py        # 12 个 unittest 用例，应该 Ran 12 tests / OK
python _端到端体检.py      # 20 道题：10 道笔记里有答案、10 道故意问笔记外
python 主程序.py "闭包是什么"
```

| 尺子 | 现在量出来的 |
|---|---|
| 端到端体检 | **误拒 0 条 / 误答 0 条**、平均 **4.2 秒/题** |
| 检索 | 10 道题 12 条标准答案，**题级 10/10、块级 11/12** 至少进一个对的块 |
| 流式 | 首字 **0.5~1.2 秒**、整问 3.4 秒（非流式要干等 2~2.1 秒才出第一个字） |
| 记录仪 | `记录.jsonl` 每问一行，20 题平均 **2.1 轮**、工具 34 次、失败 0、拒答 10 |

`记录.jsonl` 一行长这样（追加写、坏一行不坏整本、不进 git）：

```json
{"时间":"2026-10-26T19:59:01","问题":"闭包是什么","轮数":2,"工具次数":1,
 "失败":0,"首字秒":0.87,"耗时秒":3.53,"拒答":false}
```

调提示词靠这些数，不靠"感觉快了点"。整个写文件包在 `except OSError` 里 ——
记录仪挂了自己，不能连回答一起挂。

## 三只工具

| 菜单里写的名字 | 干什么 | 背后是谁 |
|---|---|---|
| `search_notes` | 语义搜索笔记，返回最相关的 3 块原文 | `检索.py` → 向量 |
| `read_ledger` | 按月份 / 分类查账，返回笔数和合计 | SQLite：`我的账本.db` |
| `add_expense` | 记一笔（金额、分类、日期、备注） | SQLite，**先过人工确认闸门** |

`description` 是写给模型看的说明书 —— 写得含糊，它就调错工具或者干脆不调。
参数在工具的 `parameters` 里声明（类型 + 必填），模型照着填。

**写操作要人点头**：`add_expense` 会先把参数摊给你看，等一个 `y`。
拒绝就不执行，但**仍然回一条 tool 消息**，否则下一次请求 400。
网页那边没有人可问 —— `允许确认` 默认 `False`，一律按拒绝处理（判定权归入口，
不是靠 `isatty()` 猜：容器里那个函数返回 `True`，猜错过一次，卡到网关 504）。

## 拒答标记：`[[无答案]]`

笔记里没有答案时，规矩要求它**整个回答只输出 `[[无答案]]`**，不许解释、猜测、道歉。

为什么搞个标记，而不是让它说「笔记里没有」：

- 判断"拒没拒答"要能用 `==` 数出来。一句人话有无数种说法，人话判不准，尺子就废了。
- 屏幕上显示的是「笔记里没有相关内容。」—— **标记是给程序看的，人话是给人看的**，中间那步在打印时替换。

流式输出时这个标记很危险：它是**边打边出**的，第 1 个字出去就露馅。
所以主程序押住开头 7 个字（`len("[[无答案]]")`），攒到第 8 个才往外放；
这一问结束时押着里还剩的，是标记就换人话，不是就照原样打出来
（代价：7 个字以内的短答案看不到逐字效果，它是最后一下蹦出来的）。

## 检索怎么挑块

`检索.py` 自己不算分，转手给 `检索_向量.py`：

1. **变向量** —— 问题和每块都交给硅基流动的 `BAAI/bge-m3`，各变成一串数字，意思越近方向越像
2. **比夹角** —— 余弦相似度：1 = 方向一样，0 = 没关系
3. **取前三** —— 按分数排，拿前 3 块

算过的向量存进 `_向量缓存.json`（不进仓库），同一块不重复花钱。

选块之前还先筛一道（`不是垃圾块()`）：正文短于 50 字**且不含反引号**的块扔掉
（「先 `.isdigit()` 再转」这种短而完整的答案要留，光杆状态栏要扔），
标题是 `## 进度` 的台账块不参加排名。28 篇笔记切成 **587 块，可用 454 块**。

> 换向量之前用"撞词"打分，同一个问句会被切成 `闭包` `包是` `是什么` —— `包是` 这种跨词碎片
> 因为罕见反而权重最高，能把真答案挤出前三。10 道题：撞词命中 **1/6**，向量 **4/6**，后来补语料、
> 改短块规则做到 **11/12**。更早那版失败的详细复盘留在 `项目笔记整理.md` 里。

## 网页版

```powershell
cd web
python -m uvicorn 服务:app --reload
```

浏览器打开 <http://127.0.0.1:8000>，一个输入框一个按钮。顺带白捡一份接口文档 `/docs`。

```
浏览器                          服务端
  │  POST /问                    │
  │  {"问题": "闭包是什么"}       │   ← 只有这一栏，Key 不在这
  │ ────────────────────────────►│  主程序.回答一个问题(问题, 块们)
  │                              │   └─ 问模型.py 自己去环境变量拿 Key
  │  {"答案": "..."}              │
  │ ◄────────────────────────────│
```

出事的牌子分两种：门卫（Pydantic 校验）拦下的是 **422**，`detail` 是**一摞**纸条；
店里（`服务.py` 的 `try/except`）挂的是 **500**，`detail` 是**一句话**。
两种形状不一样 —— 这是空着输入框点「问」踩出来的（见下面「已知不足」）。

网页这条路**不开流式**：公共网页要做流式得走 SSE，是另一件事；接口签名带默认值，
所以 `web\服务.py` 一个字没改也照样跑。

## 上线（公网版）

**网址：<https://www.modelscope.cn/studios/budon777/notes-qa-bot>**

| | |
|---|---|
| 平台 | [魔搭 ModelScope 创空间](https://modelscope.cn/studios) 免费档（2v CPU / 8G 内存） |
| 怎么建的 | 平台读 `docker.yaml` → 照 `Dockerfile` 从零搭环境（容器里连 Python 都没有，说明书从 `FROM python:3.11-slim` 写起） |
| 开张命令 | `uvicorn web.服务:app --host 0.0.0.0 --port ${PORT:-7860}` |
| 门牌 | 固定 **7860**（创空间的硬规矩） |
| Key | 两个都放在平台**「密文管理」**里，代码里没有 |

**上线是三步，不是一步：**

```powershell
git push origin main                                  # ① 推 GitHub（先开代理）
git -c http.proxy= push modelscope main:master        # ② 推魔搭（绕开代理；对面是 master）
curl -X POST ".../openapi/v1/studios/budon777/notes-qa-bot/deploy" -H "Authorization: Bearer <令牌>"
```

推上去 ≠ 上线：docker 类型的创空间不会自己重建，得再触发一次部署。
`{"success": true}` **也不算数** —— 状态是 `Building` → `Deploying` → `Running`，
真正的证据是**镜像标签里的提交号**：

```
368569-57566c5d-2026-10-26-20-15-49
       └── 提交号                     └── 构建时间
```

（这个标签接口拿不到，得带浏览器 UA 和 Referer 抓创空间 `/builds` 页面的 HTML 才有。）

**上线实测**（在公网网址上问的，不是本机）：闭包 12.7s 带出处 / 9 月餐饮 **262.00（7 笔）** 5.9s /
「帮我记一笔」被拒 2.7s —— 线上没有键盘，闸门按拒绝处理，不是卡到 504。

> ⚠️ 网址打开要等一会儿是正常的：免费档闲着会"打盹"，有人点它才醒。

两个部署坑，值得复述：

- **本机能跑 ≠ 别人能用。** `切块.py` 曾经写死 `Path("D:/CC Switch")`，服务器上没有 D 盘 →
  一块都切不出来 → 服务照样起得来、照样回话，**只是永远回「笔记里没有」**。
  修法：`Path(__file__).resolve().parent / "笔记"`，语料跟着仓库走。
- **`Dockerfile` 的续行被 CRLF 弄坏。** Windows git 把换行转成 CRLF，`ENV LANG=C.UTF-8 \`
  这种续行后面多一个看不见的 `\r`，进 Linux 就报一句和 Dockerfile 八竿子打不着的解析错。
  `.gitattributes` 里 `text eol=lf` 钉死它。

## 已知不足

1. **向量缓存每问重读一遍。** `_向量缓存.json` 6 MB，454 块的量还顶得住；块再多就慢。
   修法：服务启动时读一次、放内存里复用（`web\服务.py` 已经这么处理 `块们` 了）。
2. **网页版空着输入框点「问」，显示 `[object Object]`。** 422 的 `detail` 是一摞纸条，
   页面拿"一句话"的拼法去拼。修法：先判是不是列表，是就掏 `detail[0].msg`。
3. **网页一问一答，不记上文。** 命令行交互模式有本子（跨问题记得），网页每次新开一本。
4. **网页不开流式、同步请求。** `fetch` 发出去只能干等（几秒到十几秒），没有转圈也没有取消；
   服务端一个请求占一个线程。要抗并发得换异步客户端或加队列。
5. **测试只盖住检索一层。** `测试_检索.py` 12 个用例；主程序、工具、闸门、流式都还没有单测，
   靠 `_端到端体检.py` 这条端到端的尺子兜着。
6. **账本只能一笔一笔改。** 没有删除、没有修改，写错了只能删库重来（删 `我的账本.db` 回到 21 笔）。
