# 笔记问答机器人

拿自己的 Python 学习笔记当语料：问一句话，它从笔记里找出最相关的几段，连同问题一起发给大模型，
让模型**只根据这几段**回答。

```
 问题
  │
  ├─► 切块.py     把 27 篇笔记切成 459 个块（一个标题 + 它下面的正文）
  │
  ├─► 检索.py     给每个块打分，挑出分数最高的 3 块
  │
  ├─► 主程序.py   把 3 块的正文和问题拼成一段提示词
  │
  └─► 问模型.py   发给 DeepSeek，打印答案
```

**一句话原理：模型没读过我的笔记。** 它回答时能看到的，只有这一次请求里发给它的那些字。
所以第 2 步「挑得准不准」，直接决定第 4 步「答得好不好」。

## 怎么跑

只用到**一个**第三方库：

```powershell
pip install requests
```

Key 从环境变量读，不写进代码：

```powershell
setx DEEPSEEK_API_KEY "你的 Key"
```

> `setx` 只对**之后新开的**终端生效 —— 它改的是注册表，不是当前这个窗口。

两种跑法，都在 `问答机器人\` 目录下：

```powershell
python 主程序.py "闭包是什么"     # 命令行模式：问完这一个就退出
python 主程序.py                  # 交互模式：一直问，空回车退出
```

问句里有空格**要加引号**。命令行是按空格切词的，不引起来会被拆成几个词再拼回去，空格会被抹平。

## 四个文件各管一件事

| 文件 | 干什么 |
|---|---|
| `切块.py` | 把一篇笔记切成块：每块 = 一个标题 + 它下面的正文。靠一个 `在代码块里` 的开关跳过 ``` 里的假标题 |
| `检索.py` | 给每个块打分，返回分数最高的 3 块。只读，不写任何东西 |
| `问模型.py` | 发一次请求、把答案掏出来。外面套一层重试：网络抽风就重试，Key 错了直接认输 |
| `主程序.py` | 把上面三步串成一条线，管命令行 / 交互两种入口 |

## 检索怎么打分的

`检索.py` 里没有模型、没有向量，就是**数词**：

1. **拆词** —— 把文本里非字母数字的字去掉，然后**每 2 个字切一刀**。
   `闭包是什么` → `闭包` `包是` `是什` `什么`
2. **定价** —— 每个词值 `1 / 它在多少个块里出现过`。越罕见越值钱；
   `什么` 这种到处都是的词自动贬值到接近 0。
3. **打分** —— 问题里的词在这个块里撞上几个就加几个，**撞在标题里的算 3 倍**
   （标题是手写的「这块讲什么」，是强信号）。
4. 按分数排，取前 3。

正文短于 20 个字的块直接扔掉 —— 那是光杆标题，没东西可以发给模型。

## 已知不足

### 1. clone 下来跑不了

语料是我自己 `D:\CC Switch\` 下的 27 篇笔记，不在这个仓库里；路径还**写死**在
`切块.py` 第 49 行（`目录 = Path("D:/CC Switch")`）。要跑得改这一行，再自备一份笔记。

### 2. 拆词会切出「跨词碎片」，把真答案挤出前三

这是最该修的一处。复现：

```powershell
python 检索.py
```

问「闭包是什么」，返回的前 3 块**标题没有一个是关于闭包的**；
真正标题就叫「二、闭包」和「四、闭包 = 私有状态」的那两块，排在第 **4、5** 名，被挤出去了。

原因就在第 1 步那个「每 2 个字切一刀」：`闭包` + `是什么` 会切出一个跨词的碎片 **`包是`**。
它本身毫无意义，但**因为罕见反而拿到高权重** —— `包是` 值是 `1/3 ≈ 0.33`，
而真词 `闭包` 是 `1/12 ≈ 0.08`，**碎片比真词贵 4 倍**。
于是「碰巧含这个碎片」的块，压过了「真的在讲这个主题」的块。

**修法**：换成向量检索（embedding）。现在这版是刻意从零手写的，为的是看清每一步 ——
留在这里当一个具体的失败样本。

### 3. 没有缓存、也没有多轮

每一次提问都是全新的一次请求，不记得上一句。同一个问题问两遍就真的问两遍、花两次钱。

### 4. 权重表每问一次重算一遍

`找相关()` 里的 `建权重表(块们)` 写在函数体内，问 10 个问题就算 10 遍。
应该挪到外面算一次复用（代码里留了注释）。现在 459 个块还不明显，块再多就会慢。
