================================================================
问题：9 月我餐饮花了多少钱？
================================================================

本子第 2 条 —— 你写的 —— 用户说的话
    role = 'user'
    这条上全部的键 = ['role', 'content']
    content = 9 月我餐饮花了多少钱？

----------------------------------------------------------------
【第一句 append】本子.append(回话)
----------------------------------------------------------------

本子第 3 条 —— API 返回的 —— 模型说的话
    role = 'assistant'
    这条上全部的键 = ['role', 'content', 'reasoning_content', 'tool_calls']
    tool_calls[0].id = 'call_00_ET_xKsPhJSqkEiV8NkWMjL91553'      ← 单号，只写在它这里
    tool_calls[0].function.name = 'read_ledger'
    tool_calls[0].function.arguments = '{"month": "2026-09", "category": "餐饮"}'

----------------------------------------------------------------
【第二句 append】本子.append({"role": "tool", ...})
----------------------------------------------------------------

本子第 4 条 —— 你的代码新造的 —— 办事员的回执
    role = 'tool'
    这条上全部的键 = ['role', 'tool_call_id', 'content']
    tool_call_id = 'call_00_ET_xKsPhJSqkEiV8NkWMjL91553'  ← 和上一条那个单号是同一个
    content = 2026-09-02 餐饮 25.50 / 2026-09-03 餐饮 18.00 / 2026-09-05 餐饮 62.00 / …

================================================================
本子现在长这样（谁说的 / role / 有没有单号）
================================================================
    1. 你    system   
    2. 你    user     
    3. 模型   assistant  ← 递单子，带 tool_calls
    4. 你的代码 tool       ← 回执，带 tool_call_id
    5. 模型   assistant

----------------------------------------------------------------
那两句 append 的动作一模一样：都是往列表尾巴上加一条。
不一样的是**谁在说话、这条上有什么键**：
    assistant 那条 = 模型说的，带 tool_calls（单号在里面）
    tool 那条      = 你造的，带 tool_call_id（把同一张单号抄回来）+ 结果
本子是一份聊天记录，不是只有模型一个人在里面说话。
