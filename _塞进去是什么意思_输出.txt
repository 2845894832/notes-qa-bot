一、塞，就是字典里多了一行
==========================================================
  一开始          申请们 = {}   len = 0
  setdefault(0,空壳) 之后
                  申请们 = {0: {'id': '', 'function': {'name': '', 'arguments': ''}}}   len = 1   ← 多了一行
  递给你的 壳 是：  {'id': '', 'function': {'name': '', 'arguments': ''}}
  它就是字典里那一行吗？壳 is 申请们[0] → True

  我改 壳['id'] = 'call_a'，字典跟着变了吗？
                  申请们 = {0: {'id': 'call_a', 'function': {'name': '', 'arguments': ''}}}
  ★ 会变。因为我改的不是副本，就是那个格子里原本的东西。
    这就是 `壳 = 申请们.setdefault(...)` 之后能一直往里加的理由。

==========================================================
二、反过来：.get() 不塞，你拿到的是孤岛上的一只盒子
==========================================================
  拿到 = 账.get('乙', []) → []
  账现在是什么样？        {'甲': []}   len = 1   ← 乙根本没进去
  往 拿到 里 append 之后：
  拿到  = ['乙的第一笔']
  账    = {'甲': []}                ← 账里一个字都没多

  ★ 这只盒子飘在孤岛上：你往里装得挺开心，账里看不见。
    这类 bug 不报错、不抛异常，只是数据凭空消失 —— 最贵的那种。
    setdefault 的'塞'，就是不让它飘在外面。
