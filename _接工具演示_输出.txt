    # 一、闭包是什么
    
    **一句话：闭包 = 内层函数 + 它捕获的外层变量。**
    
    要点 [python-learning-2026-09-01.md:99]：
    
    - 外层函数**已经返回了**，被捕获的变量还活着（和生成器“暂停-恢复”是同一机制）
    - **返回的是函数对象本身**（`return inner`），不是调用结果（`return inner()`）
    - 用途是“函数工厂”：`make_power(n)` —— 同一模板，配不同“记忆”造出不同函数

    # 二、with 语句怎么用
    
    **本质：`with` 是 `try/finally` 的语法糖**，文件会在 `__exit__` 里自动 close，不用手动 `f.close()` [python-learning-2026-08-14.md:55]
    
    ## 1. 最常见：开文件
    
    ```python
    with open("test.txt", "a") as f:
        f.write("第二行\n")
    ```
    [python-learning-2026-07-02.md:97]
    
    - 标准写法是 `with open(path, mode, encoding="utf-8") as f`，**encoding 不能忘** [python-learning-2026-09-03.md:31]
    - mode：`"r"` 读 / `"w"` 覆盖写（**会先清空**）/ `"a"` 末尾追加 / `"x"` 防止误覆盖 [python-learning-2026-08-14.md:55]
    - 逐行读用 `for line in f`，配 `strip()` 去换行；数行数可以 `sum(1 for _ in f)` [python-learning-2026-08-14.md:55]
    
    ## 2. 自定义上下文管理器
    
    `__enter__` 的返回值给 `as` 后面的变量，`__exit__` 里做清理 [python-learning-2026-08-14.md:55]、[python-learning-2026-09-03.md:31]
    
    ## 3. `with` 的另一个用法：测试里要求它报错
    
    `with self.assertRaises(ValueError):` 读作「**下面这块，我要求它报 ValueError**」，`as 上下文` 跟 `except ... as e` 是同一个动作 —— **接住** [python-learning-2026-09-23.md:68]
    
    三句总结 [python-learning-2026-09-23.md:68]：
    - `with assertRaises(...)` → 你得报这个错
    - `as 上下文` → 报了你接住
    - `assertIn(..., str(上下文.exception))` → 报的内容里得有这几个字
    
    （报错要分「报没报」和「报得对不对」两件事。笔记里这条路径的完整讲解是“讲了三轮才通”，上面是三层压缩版。）
