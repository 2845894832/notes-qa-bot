你的笔记里正好有一节讲了这个问题 [python-learning-2026-09-03.md:213]：

**核心思路**：直接用 `sorted()` 比较字典时，比较的是**键**。如果要按**值**排序，需要先用 `.items()` 把字典拆成 `(键, 值)` 元组，再用 `key` 取每一对的第 2 项。

```python
d = {"苹果": 3, "香蕉": 1, "橘子": 2}

按值升序 = sorted(d.items(), key=lambda kv: kv[1])
# [('香蕉', 1), ('橘子', 2), ('苹果', 3)]

按值降序 = sorted(d.items(), key=lambda kv: kv[1], reverse=True)
# [('苹果', 3), ('橘子', 2), ('香蕉', 1)]
```

**两个容易出错的地方** [python-learning-2026-09-03.md:213]：
- `kv` 是 `(键, 值)` 元组，`kv[1]` 才是值；如果写成 `kv[0]`，就会变成按键排序。
- 如果想保留成字典，排完后再用 `dict(...)` 转换：`dict(sorted(d.items(), key=lambda kv: kv[1]))`。

补充一条相关的：如果排的是「字典列表」，就用 `key=lambda s: s["score"]`，这个写法在 [python-learning-2026-09-02.md:42] 里有示例。

你的笔记里有直接答案，总结起来是这样：

**一句话选型原则**
> CPU 密集用进程，等 IO 用线程/协程，同步库用 `to_thread` 包一层。
> [python-learning-2026-09-14.md:286]

**两条路在“等 IO”时的区别**

- **协程（asyncio）**：一个线程、一个事件循环。类比餐馆——协程版是 1 个店员 1 个窗口，把单子递进后厨就**立刻回头招呼下一位**，“哪单快好了”由**事件循环**（店员的记事本）记着。全程一个线程，实测打印出来的线程名永远是 `MainThread`，切换发生在 `await` 处。[python-learning-2026-09-14.md:59]
- **线程版**：3 个店员 3 个窗口，店员接单后去后厨**站着等**，窗口就空着；谁记着“哪单快好了”的是操作系统。线程多起来有切换和内存开销，顺序也不可预测（进度条谁先进谁排前面）。[python-learning-2026-09-14.md:59]

**实操要点：什么时候用“线程池”而不是纯协程**

> 凡是 `def`（不是 `async def`）而且会阻塞的函数，想扔进协程就必须用 `to_thread` 包一层。
> ```python
> asyncio.to_thread(同步函数, 参数1, 参数2)   # 函数名不加括号
> ```
> 它返回**可等待对象**，同时真的把同步函数丢到**线程池**里跑，事件循环不会被堵。[python-learning-2026-09-14.md:107]

笔记还特别标注：这是以后做 AI 应用开发天天要用的模式——很多大模型 SDK 只有同步接口，就是这么包一层变异步的。[python-learning-2026-09-14.md:107]

**另外两个配套知识点**

- 批量并发：`asyncio.gather` 返回的**顺序 = 传入顺序，不是完成顺序**；`gather` 遇到异常**不会**取消其他协程（要自动取消用 `asyncio.TaskGroup`）。[python-learning-2026-09-15.md:93]
- 真·并行（CPU 密集）才用 `multiprocessing.Pool`，`p.map` 帮你分发 / 并行 / 收集，`with` 用完自动关池子。[python-learning-2026-09-14.md:209] [python-learning-2026-09-11.md:295]

所以选法：**纯异步库/大量网络等待 → asyncio；阻塞的同步库 → `asyncio.to_thread`（线程池）；CPU 计算 → 进程池。**

- **pip**：Python 的第三方包安装工具，装包的基本命令是 `pip install 包名` [python-learning-2026-09-02.md:187]。
- **requirements.txt**：记录项目依赖清单的文件，由 pip 配合生成和读取：
  - 导出依赖（生成清单）：`pip freeze > requirements.txt` [python-learning-2026-09-02.md:187] [python-learning-2026-09-03.md:39]
  - 还原依赖（一键装回清单里的全部包）：`pip install -r requirements.txt` [python-learning-2026-09-02.md:187] [python-learning-2026-09-03.md:39]

也就是说，这个流程通常和 venv（每个项目一个独立虚拟环境）配合使用：在 venv 里用 pip 装包，再用 `pip freeze` 把当前环境的包清单写入 requirements.txt，换机器或换人时用 `pip install -r requirements.txt` 一键还原环境 [python-learning-2026-09-02.md:187]。
