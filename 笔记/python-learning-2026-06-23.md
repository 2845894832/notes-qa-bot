## 🧱 元组 (tuple)

### 基本用法
```python
# 创建 — 用圆括号 ()
info = ("小明", 17, 99)

# 索引 — 用方括号 []
print(info[0])   # "小明"
print(info[2])   # 99

# 解包 — 一次性拆给多个变量
name, age, score = info
print(name, age, score)  # 小明 17 99

# 两数交换（背后就是元组）
a, b = b, a
```

### 核心特性：不可变 (immutable)
```python
info[1] = 18   # ❌ TypeError: 'tuple' object does not support item assignment
```
一旦创建，不能增、删、改。

### 函数返回多个值 = 返回元组
```python
def get_user():
    return "小明", 17       # 实际返回 ("小明", 17)

result = get_user()
print(type(result))         # <class 'tuple'>
```

### 元组 vs 列表
| 特性 | 列表 `[]` | 元组 `()` |
|------|----------|----------|
| 可变 | ✅ | ❌ |
| 索引 | ✅ | ✅ |
| 解包 | ✅ | ✅ |
| 何时用 | 数据会变 | 数据不变 |

## 🔢 集合 (set)

### 基本用法
```python
# 创建 — 用花括号 {} 或 set()
nums = {1, 2, 3}

# 去重 — 秒杀
list(set([1, 2, 2, 3, 3, 3]))   # [1, 2, 3]
```

### 集合运算
```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

a & b    # 交集：{3, 4}         — 两边都有
a | b    # 并集：{1,2,3,4,5,6}  — 合并去重
a - b    # 差集：{1, 2}         — a有b没有
```

### 增删操作
| 方法 | 元素存在 | 元素不存在 |
|------|---------|-----------|
| `.add(x)` | — | 添加 |
| `.remove(x)` | ✅ 删除 | ❌ KeyError 报错 |
| `.discard(x)` | ✅ 删除 | ✅ 不报错，跳过 |

### 核心特性：无序、无索引
```python
s = {"苹果", "香蕉"}
s[0]   # ❌ TypeError: 'set' object is not subscriptable

# 但可以遍历
for item in s:
    print(item)   # 每次顺序可能不同！
```

## 🔑 今日要点

1. **元组 = 不可变列表**，用 `()` 创建，适合存不变的数据
2. **解包**：`a, b, c = tuple` 比索引优雅
3. **集合 = 无序不重复**，用 `{}` 或 `set()` 创建
4. **集合运算**：`&` 交集、`|` 并集、`-` 差集
5. **remove vs discard**：remove 找不到报错，discard 不报错
6. **集合无索引**：因为无序，只能用 for 遍历
