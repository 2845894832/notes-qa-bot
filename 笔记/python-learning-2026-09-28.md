## 一、每日综合题 · 轮次 6「文件与路径」

### 题目

**门店归还记录 → 结算 → 写日报文件。**

输入数据 `D:\CC Switch\_练习数据\20260928_归还记录.txt`（10 行，其中 **4 处故意埋的缺陷**）：

```
A-001,望京店,13300133000,95,3.0
B-002,望京店,13800138000,30,2.5
C-003,中关村店,13900139000,60,2.0
```

**规则**：每行 5 段（设备号,门店,手机号,分钟,单价）；前 30 分钟免费；

| `.splitlines()` | 切行 |

| `raise ... from 原始错` | `int()` / `float()` 失败时保留原始原因 |
| `//` 和 `%` | 算档数：`超出 // 30` + `超出 % 30 > 0` |
| 类型注解 | `list[str]`、`dict[str, float]`、`tuple[str, str, int, float]` |
| `unittest` | 14 条测试 |

### ⭐ 今天最值钱的一条：**写了不运行**

这是今天最该记住的东西，跟知识点无关，跟**习惯**有关。

**两处一模一样的问题**：

1. **整份文件末尾没有运行入口。**
   文件里定义了一堆函数和类，但**没有 `if __name__ == "__main__": main()`**。
   跑 `python daily_2026-09-28.py` —— **屏幕空白，而且不报错**。
   不报错最要命：你会以为"没问题"。

2. **10 条测试写了，但没接 `unittest.main(...)`。**
   写完测试跑一次，输出里只有 `main()` 打的那几行，
   **一条测试都没跑**。接上 `unittest.main(argv=[""], exit=False)` 再跑：

   ```
   F..F..F.....
   FAILED (failures=3)
   Ran 10 tests in 0.002s
   ```

   **3 条当场现形**：
   - 第 298 行 `assertEqual((60,3), 3.0)` —— **函数名 `计费` 整个丢了**，变成一个元组
   - 第 301 行 `assertEqual((90,3), 6.0)` —— 同上
   - 第 310 行 `assertIn("五段", ...)` —— 消息里写的是 `"5 段"`，**对不上**

**这三条本来是你自己写的测试就能抓出来的。** 只要接上那一行，跑一次，它自己就会告诉你。

> **一句话**：**写完 ≠ 写完。跑出输出，才叫写完。**
> 测试也一样 —— **没看到 `Ran N tests`，就等于没写。**

### 其余踩的坑（按文件顺序）

| 位置 | 问题 | 改成 |
|---|---|---|
| 顶部常量 | `台账` 指向了**日报文件**（读错文件） | 拆成 `数据目录` / `记录文件` / `日报文件` 三个名字 |
| `读记录` | `try/except` 包住了 `.exists()` —— **它不抛异常**，白写 | 直接 `if not 路径.exists(): raise ...` |
| `读记录` | `raise f"字符串"` | `raise 记录文件不存在(f"...")` |
| `读记录` | `for 一行 in 一` 里又 `一.readline()` —— **双重读取**（`for` 已经在逐行拉了） | 只用 `for 一行 in 内容.splitlines()` |
| `读记录` | `append(一行, 0)` —— list 的 append 只吃**一个**参数 | `append(一行)` |
| `解析` | 段数判断写成 `!= 4` | `!= 5` |
| `解析` | `int(分钟文本)` 没接住异常 | `try/except ValueError as 原始错: raise 记录格式错误(...) from 原始错` |
| `解析` | `except 记录格式错误` | `except ValueError`（**接住的是原始异常类型**） |
| `解析` | `单价文本 <= 0` —— 拿**字符串**比大小 | 先 `float()` 转成数字再比 |
| `解析` | 返回的是**字符串**，不是 int/float | 返回 `分钟, 单价`（数字） |
| `结算` | `解析(原始行)` —— 传错了参数 | 传那一行本身 |
| `结算` | 失败清单 `append((一条, ...))` 多了一层括号 | 直接 `append(f"...")` |
| `结算` | 明细里漏了 `时长文字(分钟)` | 补上 |
| `拼日报` | `总金额` 没定义就用了 | 先算出来 |
| `拼日报` | `set(明细[1], 明细[3])` | `{对[1] for 对 in 明细}` |
| `拼日报` | `明细.sort()` —— 它**返回 None**，同时又想接返回值；`reversed=` 也写错了 | `sorted(明细, key=..., reverse=True)` |
| `写日报` | `open("a")` 追加模式 | 本题要**覆盖**，用 `write_text`（默认覆盖）|
| `写日报` | `write("{内容}\n")` —— **漏了 `f`** | `write(内容 + "\n")` |
| `main` | **8 行 print 全部漏 `f`** | 每行都补 `f` |

> 📌 **`漏 f`** 值得单独记：漏了 `f` 不报错，只是把 `{内容}` 原样打出来。
> 这类"**不报错但结果不对**"的错，只能靠**看输出**发现 —— 又绕回上面那条。

### 踩的四个坑（下次照这个来）

1. **GitHub 账号名是 `2845894832`，不是 `budon`。**
   `budon` 是 git 里的 `user.name`（**显示名**）—— 显示名 ≠ 账号名。
   写成 `github.com/budon/...` → `Repository not found`。
   **要确认账号名**：看浏览器地址栏，或查 `https://api.github.com/users/<名字>`。

2. **国内直连 GitHub 完全不通。**
   实测：百度 / 码云 **200**，GitHub / Google **全超时**（DNS 都不通）。
   机器上装了 **Clash Verge**（`C:\Program Files\Clash Verge`），混合端口 **`127.0.0.1:7897`**。
   **push 之前必须先开 Clash。** git 已配好全局代理：
   ```
   git config --global http.proxy http://127.0.0.1:7897
   ```
   哪天不开 Clash 了，用 `git config --global --unset http.proxy` 取消。

   **排查顺序（两步）**：
   ```powershell
   netstat -ano | findstr LISTENING | findstr 7897
   curl -x http://127.0.0.1:7897 -o /dev/null -w "%{http_code}" https://github.com
   ```
   第二条返回 `200` 就通了（约 1 秒）。

3. **终端一会儿 PowerShell、一会儿 cmd**，同一个 `cd` 两种写法不同
   （cmd 要 `/d`，PowerShell 不要）。
   → **最省事的写法是 `git -C "D:\路径" <命令>`**，两个终端都能直接粘，不用先 cd。

4. **粘长命令会被拆成两行。**
   `git remote add origin` 粘过去，网址掉到了**下一行**、甚至跑到命令**前面**。
   → 命令尽量短；实在长就提醒自己"整行一次粘完"。
