### 涉及的知识点

| 知识点 | 在本题里的落点 |
|---|---|
| `import X` vs `from X import Y` | 只绑 `Y`，**不绑 `X`** → `NameError` |
| `__name__` 的两副面孔 | 直接跑 = `"__main__"`；被 import = 模块名 |
| `if __name__ == "__main__":` | `main.py` 和 `计费.py` 的自测入口都得自己接 |
| 文件夹 → 包 | `__init__.py` 是门牌 |
| 相对导入 `from .读记录 import ...` | 那个点 = "本包内" |
| 门厅搬名字（re-export） | `__init__.py` 三行 import，门外就多了 10 个名字 |
| **`__all__` 必须是字符串列表** | 写对象 → `TypeError` |
| `unittest.main(verbosity=2)` | **只扫自己这个模块**，且会 `sys.exit()` |
| 包被直接跑 | `python 结算包\读记录.py` → `ImportError: attempted relative import with no known parent package` |
| `tempfile.TemporaryDirectory` | 用完自己消失的文件夹 |

### 今天讲通的四个点（都是他自己问的）

1. **`from .读记录 import ...` / `from 结算包 import ...` 两句 import 不一样，
   为什么门外侧还能用 `拼日报` / `结算` / `写日报`？**
   → 门厅里**不止一行**。`__init__.py` 一共三行 import，搬进去 **10 个名字**
   （5 个来自读记录 + 3 个来自计费 + 2 个来自报告）。门外看到的是一整张桌子，
   不是他盯着的那一行。（现场把他真包的门厅 dump 出来数过：11 个名字 = 10 个 + `版本`。）

2. **`if __name__ == "__main__": unittest.main(verbosity=2)` 为什么要加？**
   → `unittest.main()` 会 `sys.exit()`。不保护的话，谁 import 它谁被"连坐"退出。
   实跑对照过：甲（没保护）被 `import` 进来 → `Ran 0 tests`、`NO TESTS RAN`、退出码 5，
   把引它的程序一起带走；乙（有保护）被 import 进来 → 一行测试都不跑，安然无恙。

3. **`tempfile.TemporaryDirectory` 是哪来的？**
   → 三跳，跟他早会的 `pathlib.Path` 一模一样：
   `import tempfile`（模块）→ `tempfile.TemporaryDirectory`（类）→ 加括号（造一个出来，
   **硬盘上真建了文件夹**）。`with` 负责"进去时建、出来时自动 `cleanup`"。
   实跑证据：`这路径现在真在硬盘上吗： True` → `调完 cleanup 之后还在吗： False`。

4. **`assertEqual(临时文件.read_text(...), 内容 + "\n")` 这两边怎么对等的？**
   → 因为**本来就是同一串字符，只是写了两遍**。
   `写日报` 内部就是 `路径.write_text(内容 + "\n", ...)`，
   所以硬盘上躺着的**就是** `内容 + "\n"`；`read_text` 只是把它原样搬回来。
   实跑证据（"能数的数"）：`内容` **408** 个字符，读回来 **409** 个，**多 1 个就是那个换行**。
   → `读回来 == 内容` 是 `False`，`读回来 == 内容 + "\n"` 是 `True`。
   左边是"从硬盘念一遍"，右边是"把要写的那串重算一遍" —— 相等，就说明写读没走样。

### ⭐ 顺手挖出一个真 bug（今天最值钱的一段）

README 里要写「已知不足」，我没凭印象编，而是**去量了一遍**：

```
问「闭包是什么」→ 前 3 块，标题没有一个是讲闭包的
真正讲闭包的两块：第 4 名、第 5 名 —— 被挤出去了
```

**第一层原因：跨词碎片拿到了高权重。**

| 词 | 权重 | 出现在 | 是什么 |
|---|---|---|---|
| `包是` | **0.3333** | 3 个块 | 跨词碎片，没意义 |
| `闭包` | 0.0833 | 12 个块 | 真词 |

拆词是「每 2 个字切一刀」，`闭包` + `是什么` 就切出一个**跨词的碎片** `包是`。
它本身毫无意义，但**因为罕见反而贵** —— **碎片比真词贵 4 倍**。

**第二层原因（这层是我差点漏掉的）：那 3 块为什么"碰巧"含这个碎片？**

不是碰巧。它们来自同一篇笔记 `2026-09-27.md`，而那篇**在讲 `sys.argv` 时，
拿「闭包是什么」当示例问句**：

```python
sys.argv = ["主程序.py", "闭包是什么"]     ← 就这儿切出了「包是」
```

那一块里「闭包」出现了 **11 次**，**一个字都没讲闭包本身**。

> ⭐ **一句话**：**检索器分不清「在讲闭包」和「只是提到了闭包这两个字」。**

**跑完整条线，结果最漂亮：**

```
===== 问：闭包是什么，挑中 3 块 =====
  python-learning-2026-09-27.md:243  ### 做了什么
  ...:259  ### 卡住的点：`" ".join(sys.argv[1:])` ...
  ...:284  ### black：只改长相，不改意思
--------------------------------------------------
笔记里没有
```

**检索错了，模型没错。** 挑出来的 3 块确实没讲闭包，模型就照实说「笔记里没有」——
提示词里那句「如果笔记里没有，就说笔记里没有」把幻觉挡住了。
**这个失败看起来像"程序坏了"，其实是"程序老实"。**

> ⚠️ **而且这条是"新坏"的**：程序在 **09-25 第一次测「闭包是什么」时是答对的**。
> 坏在 **09-27** —— 那天新写的笔记把「闭包是什么」当例子用了一下，
> 就把两篇本来不相干的笔记连上了。
> **语料一变，检索就可能坏，而且它不会报错。** 这条比 bug 本身值钱。

修法是换向量检索（embedding）。现在这版留着当**一个具体的失败样本** ——
面试官问"你的检索有什么问题"，能当场跑给他看、还能说清为什么。
